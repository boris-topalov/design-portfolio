# Портфолио — статический сайт

Многостраничный статический сайт-портфолио продуктового дизайнера: 4 HTML-страницы,
две темы (тёмная по умолчанию / светлая), переключатель языка RU/EN, локальный
вариативный гротеск и скрипт-проверка полноты словаря.

## Как открыть

Двойной клик по `index.html` — сайт работает прямо с `file://`.

Никакой сборки, сервера, `fetch()`, ES-модулей и внешних зависимостей. Только HTML,
CSS, ванильный JS и один локальный файл шрифта. Если открыть через `file://`, всё
работает так же, как на хостинге (проверено в Chromium: тема, язык, шрифт).

assets/js/i18n.js               # словарь текстов window.I18N (RU/EN)
assets/js/main.js               # применение языка + переключатель темы
assets/js/motion.js             # движение: морф-заголовок, остров, tilt, hold, стрим

## Темы

Две темы, переключаются кнопкой `.theme-toggle` (`#themeToggle`) в шапке.

- состояние живёт в атрибуте `<html data-theme="dark|light">`; по умолчанию `dark`;
- выбор хранится в `localStorage['portfolio.theme']`;
- в `tokens.css` темы описаны селекторами `[data-theme="dark"]` и `[data-theme="light"]`,
  поэтому переключение — это смена значений CSS-переменных, без перерисовки разметки;
- тёмные и светлые полосы (hero, `case-block`, `section--light`, `cta-band`) задают
  локальную область токенов: они остаются тёмными/светлыми в обеих темах;
- в `<head>` каждой страницы стоит короткий inline-скрипт, который выставляет
  `data-theme` из `localStorage` до первой отрисовки — иначе при выборе светлой темы
  видна вспышка тёмной;
- `body` меняет `background-color` и `color` с переходом 0.3s; при
  `prefers-reduced-motion: reduce` переходы отключены.

Кнопка темы — иконка (солнце в тёмной теме, луна в светлой), поэтому `main.js`
не перезаписывает её содержимое, а обновляет только локализованный `aria-label`
(`theme.toLight` / `theme.toDark`). Язык и тема независимы: можно смотреть сайт
по-английски в светлой теме.

## Типографика

Заголовки и текст — один вариативный гротеск **Manrope** (wght 200–800, Cyrillic +
Latin, SIL OFL 1.1). Файл лежит в `assets/fonts/Manrope-Variable.woff2` (52.5 КБ),
подключён через `@font-face` в `base.css` с `font-display: swap` и предзагружается
`<link rel="preload" as="font">`. Внешних CDN нет.

Почему не Archivo, как планировалось изначально: в Archivo нет кириллицы, а сайт
двуязычный — русские заголовки отваливались бы в системный шрифт. Имя семейства
в `@font-face` совпадает с первым значением `--font-display` / `--font-sans`
в `tokens.css` (`"Manrope"`), поэтому стек токенов менять не пришлось.

## Локализация

- Все видимые тексты размечены атрибутом `data-i18n="ключ"`.
- Тексты лежат в `assets/js/i18n.js` в объекте `window.I18N`:
  `window.I18N[pageId][lang][key]`, где `pageId` — значение `<body data-page="…">`.
- Язык хранится в `localStorage` под ключом `portfolio.lang` (по умолчанию `ru`).
- Кнопка `#langToggle` в шапке переключает язык: в русском режиме показывает `EN`,
  в английском — `RU`. Меняются `<html lang>` и `<html data-lang>`.
- Ключи — плоские, в точечной нотации: `nav.cases`, `hero.title`, `case.yt.title`.
- Строка доверия в hero собрана из трёх ключей (`hero.meta.years`, `hero.meta.role`,
  `hero.meta.domains`); между ними стоят отдельные элементы `.hero__meta-sep`
  (`aria-hidden="true"`, текст `·`), поэтому при переносе строка не начинается
  с висячего разделителя.

Страницы и их `pageId`:

| Файл | `data-page` |
| --- | --- |
| `index.html` | `index` |
| `cases/youtravel.html` | `case-youtravel` |
| `cases/finance-dashboard.html` | `case-dashboard` |
| `cases/case-3.html` | `case-3` |

## Движение (`assets/js/motion.js`)

Один IIFE-модуль без библиотек, модулей и запросов. Каждый эффект включается
только если на странице есть его разметка, поэтому один и тот же файл подключён
и на главной, и в кейсах.

| Эффект | Классы / атрибуты | Что делает |
| --- | --- | --- |
| Морф-заголовок | `.word-roll.is-rotating`, `.word-roll__word` | четыре фразы лежат в одной ячейке grid; JS пружиной меняет видимую, высота слота зафиксирована `min-height` по замеру — строка не «дышит» |
| Scramble | `.scramble` | раскодировка подписи случайными глифами 200–400 мс: один раз при попадании во вьюпорт + на hover/focus |
| Морф-остров | `[data-morph-island]`, `[data-morph-toggle]`, `[data-morph-panel]` | кнопка-пилюля раскрывает панель навигации классом `.is-open`; Esc и клик вне закрывают, `aria-expanded` и `inert` синхронизированы |
| Магнитные кнопки | `.magnetic` | сдвиг к курсору через `--mg-x` / `--mg-y`, rAF, сброс на `pointerleave`, только `pointer: fine` |
| Tilt карточек | `.card-tilt` | наклон `--tilt-x` / `--tilt-y` (deg), подсветка `--mx` / `--my` (%), сдвиг обложки `--tilt-shift-*`; на тач не включается |
| Раскрытие кейса | `.card-expand`, `.card-expand__body`, `[data-expand-toggle]`, `[data-expand-close]`, `.case-grid.has-open` | нижний лист поверх карточки, `.is-open` + `aria-expanded`; тот же обработчик ставит контейнеру `.has-open`, пока открыта хотя бы одна карточка; закрытие по Esc/кнопке возвращает фокус на триггер |
| Hold-to-message | `[data-hold]`, `.hold-btn__fill/__ring` | удержание 800 мс пишет `--hold-progress` 0→1 и открывает ссылку; отпускание раньше — плавный сброс |
| Стриминг | `.stream`, `[data-stream]` | текст печатается по буквам один раз при входе в вьюпорт, курсор `.stream__cursor` гаснет по `.is-done` |
| Scroll-reveal | `.reveal` → `.is-visible` | IntersectionObserver, порог 0.15, срабатывает один раз |
| Cursor glow | `.cursor-glow`, `--cursor-x` / `--cursor-y` | пятно за указателем, один rAF на движение, только `pointer: fine` |
| Бегущая строка | `.marquee`, `.marquee__track` | JS один раз дублирует элементы дорожки, CSS гонит её на −50% без шва |
| Плавающий CTA | `[data-sticky-cta]` | появляется после первого экрана классом `.is-visible`; пока в вьюпорте `.cta-band` (IntersectionObserver, порог 0.25), получает `.is-hidden` и уступает место финальному призыву — и на главной, и на страницах кейсов |

**Клавиатура на hold-кнопке.** Мышь и тач держат 800 мс. С клавиатуры Enter/Space
держат 300 мс: зажатая клавиша не даёт тактильной обратной связи, а 800 мс
ожидания без визуального прогресса читаются как «кнопка не работает». Отпускание
раньше 300 мс отменяет действие, `click` без удержания блокируется.

**Отключение.** При `prefers-reduced-motion: reduce` модуль не запускает ни одного
цикла: `motion.js` не вешает класс `js-motion`, `.reveal` сразу получает
`.is-visible`, заголовок показывает первую фразу, стрим печатает текст мгновенно,
tilt/магнит/пятно/бегущая строка выключены, hold-кнопка работает как обычная
ссылка, `.sticky-cta` получает и снимает `.is-hidden` без transition (переход
снят инлайном), а логика показа/скрытия остаётся той же. Это же поведение включается на лету, если системную настройку поменять
при открытой странице.

**Как добавить эффект.** Функция-инициализатор в том же IIFE, вызов из `boot()`
через `all('.селектор').forEach(init…)`, ранний `return` при `reduced()`. Правила:
анимируем только `transform` и `opacity`; геометрию читаем один раз до записи
(или в том же кадре до неё), а не после; слушатели — с `{ passive: true }`;
никаких inline-layout-стилей, состояние выражается классом (`.is-open`,
`.is-visible`) или CSS-переменной.

## Проверки

```bash
python scripts/check_i18n.py     # словарь: все data-i18n ключи есть в ru и en
python scripts/qa_check.py       # структура: файлы, ссылки, alt, запрещённый JS, темы, шрифт, офлайн
python scripts/contrast_check.py # контраст токенов (WCAG 2.1) в обеих темах
python scripts/motion_check.py   # движение: reduced-motion, ARIA, вес JS, пассивные слушатели
```

Все четыре скрипта — stdlib, без зависимостей, возвращают `exit 1` при провале
(удобно для CI и pre-commit):

| Гейт | Что валит сборку |
|------|------------------|
| `qa_check.py` | битая ссылка, `<img>` без `alt`, `fetch(`/`import`/`export`/`require(`, не 2 `.case-card` + 1 `.request-card` на главной, дерево `aria-controls` у expand-кнопок, страница без `motion.js` или `<nav class="nav">`, внешний `url()` в CSS, шрифт не из `assets/fonts` |
| `contrast_check.py` | `--text`/`--bg`, `--muted`/`--bg`, `--on-accent`/`--accent` ниже 4.5:1 в любой из тем; поверхности, `--accent-2`, `--accent-ink` и градиент — advisory (печатаются, не гейтят) |
| `motion_check.py` | нет раннего выхода при `prefers-reduced-motion`, нет сброса transition/animation в CSS, внешняя зависимость в JS, класс движения без разметки или стилей, вес `assets/js/*.js` больше **60 КБ**, `.hold-btn`/`.card-expand` без ARIA и клавиатуры; `{passive:true}` — только WARN |

Обновить палитру — значит прогнать `contrast_check.py` и приложить вывод к
коммиту; гейт читает `assets/css/tokens.css`, отдельных «эталонных» значений в
скрипте нет.

`check_i18n.py` вырезает объект после `window.I18N =`, парсит его через `json.loads`,
собирает все ключи `data-i18n` с четырёх страниц и сверяет их с секциями `ru` и `en`.
Поэтому словарь держим в строго JSON-совместимом виде: двойные кавычки, без trailing
comma, без комментариев внутри объекта.

Те же проверки прогоняются и для новых компонентов движения: все строки морф-заголовка
(`hero.rotate.1…4`), подписи hold-кнопки (`hold.label`, `hold.hint`) и факты в
`.card-expand__body` (`cases.c1.fact1…3`) лежат в словаре в двух языках.

## Заметки по реализации

- `main.js` — IIFE без модулей: `document.querySelectorAll('[data-i18n]')` + `textContent`.
  `fetch`/`import`/`export` отсутствуют, сайт работает по `file://`.
- Тексты без перевода (логотип, `alt` изображений, `aria-label` навигации) остаются
  статичными; `aria-label` кнопок темы и языка локализуется в `main.js`.
- Если `localStorage` недоступен (приватный режим, ограничения `file://`), выбор
  темы и языка просто не сохраняется — сайт работает на значениях по умолчанию.
- CSS-переменные контракта: `--bg`, `--surface`, `--surface-2`, `--text`, `--muted`,
  `--line`, `--accent`, `--accent-strong`, `--accent-soft`, `--accent-ink`,
  `--on-accent`, `--font-display`, `--font-sans`, `--fs-hero`, `--fs-h2`, `--fs-h3`,
  `--fs-body`, `--fs-small`, `--space-1…--space-6`, `--radius`, `--radius-sm`,
  `--radius-pill`, `--max`, `--shadow`, `--grad-1…--grad-4`, `--glow`,
  `--grain-opacity`, `--fs-display`, `--tracking-display`, `--shadow-glow`,
  `--header-h`.
- Правки по отчёту Lazyweb: F1 — заголовок hero описывает специализацию, а не общий
  слоган; F3 — постоянный CTA: `.header-cta` в панели морф-острова плюс плавающий
  `.sticky-cta`, который появляется после первого экрана;
  F4 — карточка «Кейс в подготовке» заменена на `.request-card` про кейсы под NDA;
  F5 — опыт и уровень вынесены в `.hero__meta` отдельной строкой.
- `main.js` после смены языка/темы бросает `langchange` / `themechange` на `document`:
  `motion.js` по ним заново измеряет морф-заголовок и пересобирает стримы, не зная
  ничего о словаре.
- Легаси-токены `--grad-1…--grad-3` объявлены алиасами `--grad-4` в `@layer` внутри
  `base.css`: контракт из `qa_check.py` держится, но неслоёное значение из
  `tokens.css` всегда перекрывает алиас.
